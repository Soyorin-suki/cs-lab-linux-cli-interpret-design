# Makefile 相关学习笔记

通过形如:
```Makefile
目标: 依赖
	命令
```
的方式创建一个命令

`=`是延时展开，用到的时候才会读取最新version，`:=`是直接创建，根据上面若干行的内容进行创建，`:`是依赖，表示左边的内容要求右边的内容存在并是最新的



以`$`开头的都是自动变量:
|符号|意义|
|--|--|
`$@`|当前目标文件
`$<`|第一个依赖文件
`$^`|所有依赖文件
`$?`|更新过的依赖文件

类似`.PHONY`的是伪目标

- `.PHONY` 显示告诉`make`，后面的名字不是真实的文件

特殊前缀
- `@`表示静音，不打印执行的命令
