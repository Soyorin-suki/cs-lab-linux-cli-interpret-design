# 计算机实训-linux命令行解释器设计

这是武汉理工大学计算机实训课程的课设项目

## 项目简介

## 使用
```cmd
make
make run
```


## 要求完成的主要任务
1. 分析命令解释程序与内核的关系
2. 学习 linux 的系统调用
3. 在 linux 环境下使用 C 语言编写一个 shell 命令解释器程序 user-sh
   1. 设计类似于目前流行的 shell 解释程序，如 bash、csh
   2. 能够执行常用的内部命令，例如，cd, ls, history, exit 等
      1. cd <路径>: 切换目录
      2. ls: 显示指定目录下的文件、目录，及磁盘空间等相关信息
      3. history: 显示控制台中曾经输入过的命令
      4. exit: 退出控制台
